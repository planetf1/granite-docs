# Welcome to IBM Granite

IBM Granite is a family of enterprise-grade foundation models designed for business applications. These models are built with transparency, accountability, and governance in mind, making them ideal for enterprise deployment.

## Run Granite with Ollama

Get started with IBM Granite in 3 simple steps:

<Steps>
  <Step title="Install Ollama">
    Download and install Ollama from [ollama.com](https://ollama.com)
  </Step>
  
  <Step title="Pull Granite">
    Run the following command to download Granite:
    ```bash
    ollama pull granite3.3
    ```
  </Step>
  
  <Step title="Start chatting">
    Start a conversation with Granite:
    ```bash
    ollama run granite3.3
    ```
  </Step>
</Steps>
