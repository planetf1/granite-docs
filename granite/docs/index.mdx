## Run Granite with Ollama

Get started with IBM Granite:

<Steps>
  <Step title="Install Ollama">
    Download and install Ollama from [ollama.com](https://ollama.com)
  </Step>

  <Step title="Pull Granite">
    Run the following command to download Granite: 
    <CodeGroup>
    ```bash Bash
    
    ollama pull granite3.3

    ```
    </CodeGroup>

  </Step>

  <Step title="Start chatting">
    Start a conversation with Granite: 
    <CodeGroup>
    
    ```bash Bash
    ollama run granite3.3 
    
    ```
    </CodeGroup>

  </Step>
</Steps>
