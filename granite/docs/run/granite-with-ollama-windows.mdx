## Overview

In this guide, we'll use [Ollama](https://ollama.com/), an open-source tool that makes it easy to download and run AI models locally.

---

## 1. Download Ollama

You can download the installer directly from [Ollama](https://ollama.com/download/windows).  
Alternatively, use PowerShell to download and run the installer:

```powershell
$url = 'https://ollama.com/download/OllamaSetup.exe'
$outputPath = 'C:\Downloads\OllamaSetup.exe'
Invoke-WebRequest -Uri $url -OutFile $outputPath
& $outputPath
```

---

## 2. Install Ollama

After downloading, double-click **OllamaSetup.exe** and follow the on-screen instructions to complete the installation.

---

## 3. Download Granite Models

Ollama supports a range of IBM Granite models. Larger models provide better results but require more resources.

Example models:

- `granite3.3:8b`
- `granite3.3:2b`
- `granite3.2:8b`
- `granite3.2:2b`
- `granite3.2-vision:2b`
- `granite3.1-guardian:2b`
- `granite3.1-guardian:8b`
- `granite3.1-moe:1b`
- `granite3.1-moe:3b`
- `granite-code:20b`
- `granite-code:3b`

Use PowerShell to download Granite 3.3 (8b variant):

```powershell
ollama pull granite3.3:8b
```

---

## 4. Run Granite

To start chatting with Granite:

```powershell
ollama run granite3.3:8b
```

If you want to use a different variant, replace the model name (e.g., `granite3.3:2b`).

---

## 5. Notes on Context Length

<Note>
By default, Ollama runs models with a short context length to save memory.  
For longer conversations, you can adjust it by setting:

```
/set parameter num_ctx <desired_context_length>
```

The largest supported context for Granite 3.1 models is `131072` (128k).

</Note>

---

## 6. Using the API

You can also interact with Granite programmatically using Ollama’s OpenAI-compatible API:

```powershell
curl -X POST http://localhost:11434/v1/chat/completions `
  -H "Content-Type: application/json" `
  -d '{
        "model": "granite3.3:8b",
        "messages": [{"role": "user", "content": "How are you today?"}]
      }'
```
