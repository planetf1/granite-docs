[IBM watsonx Code Assistant](https://marketplace.visualstudio.com/items?itemName=IBM.wca-core) provides a lightweight AI coding assistant for individual developers to use and explore a locally hosted IBM Granite large language model using Ollama. It supports popular languages like Python, Java, and C++ and integrates with Visual Studio Code.

For enterprises, watsonx Code Assistant scales seamlessly to deliver advanced features, robust performance, and enterprise-grade optimizations. Users can transition effortlessly from local experimentation to full-scale production on IBM Cloud, ensuring smooth adoption for diverse development needs.
